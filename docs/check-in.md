# The check-in

*A stage-aware set of questions, so "is this normal?" has an answer without a
phone call every time. It sorts what you report into three piles: ordinary,
worth mentioning at the next appointment, and worth a call today.*

**What this is not.** It does not diagnose anything, it cannot examine you, and
it only knows the questions written below. **Anything that feels wrong and is
not on the list is still a reason to call.** A checklist that talks someone out
of an instinct has done harm, so the result always says so.

**How the levels work.** Any single `call` answer decides the whole result —
the ordinary answers around it do not dilute it, and nothing is ever scored or
averaged. A pregnancy is not a thing to get a mark out of ten for.

## Questions

`From` and `Until` are gestational weeks, inclusive of From and exclusive of
Until, so a question runs only in the stage where it means something. `Concern
on` says which answer is the one that matters — for most it is *yes*, but for
fetal movement and the care checkpoints it is *no*.
